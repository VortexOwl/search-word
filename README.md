
# 🔎 Search Word

> Приложение для поиска русских существительных слов по заданным фильтрам:

- длина слова;
- обязательные символы;
- исключённые символы;
- фиксированные символы на определённых позициях;
- исключённые символы для отдельных позиций.

## ✨ Возможности

- **Кроссплатформенность:** полная поддержка операционных систем Windows и Linux.
- **Поиск слов:** фильтрация русских слов по заданным критериям.
- **Экспорт данных:** автоматическое сохранение сформированного отчета в текстовый файл.
- **Управление архивом:** ручная очистка директории с ранее созданными отчетами средствами приложения.

## 📥 Установка

Готовые версии приложения доступны на странице Releases.

Выберите архив для своей операционной системы:

| Операционная система | Скачать                                                               |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| Windows                                 | [search-word-win.zip](../../releases/latest/download/search-word-win.zip)     |
| Linux                                   | [search-word-linux.zip](../../releases/latest/download/search-word-linux.zip) |

Распакуйте скачанный архив в удобную папку.

## 🚀 Запуск

### Windows

1. Скачайте архив `search-word-win.zip`.
2. Распакуйте архив.
3. Запустите файл приложения из распакованной папки.
4. Дождитесь открытия веб-интерфейса в браузере.

### Linux

1. Скачайте архив `search-word-linux.zip`.
2. Распакуйте архив.
3. Сделайте файл приложения исполняемым:

```bash
chmod +x search-word
```

4. Запустите приложение:

```bash
./search-word
```

5. В выбранном по умолчанию браузере откроется адрес:

```text
http://localhost:8000/search-word/new
```

## 📝 Создание отчёта

На странице **«Поиск слов»**:

| Параметр                                                | Описание                                                                                                                                                      | Пример                 |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Количество символов слова                | Задаёт длину слова, которое нужно найти                                                                                              | `5`                        |
| Символы, которые есть в слове           | Перечисляет символы, которые точно присутствуют в слове                                                               | `аон`                   |
| Символы, которых нет в слове             | Перечисляет символы, которые не должны встречаться в слове ни на одной позиции                      | `лт`                     |
| Символы на фиксированных позициях | Задаёт маску слова: известные буквы ставятся на свои места, а неизвестные заменяются на`+` | `а++о+`                  |
| Исключённые символы по позициям     | Указывает, какие буквы не должны стоять на фиксированных позициях                                             | `н`------`о`           |
| Сохранить результат в файл               | Определяет, вывести результат на веб-странице или сохранить результат как текстовый файл. | `Да` или `Нет` |

## 📄 Формат отчёта

Пример результата:

```text
ажгон аксон амвон анион аргон аэрон
```

В случае отсутствия совпадений слов по заданным критериям приложение информирует об этом пользователя.

## 🧹 Очистка отчётов

На странице **«Очистка папки отчётов»**:

1. Нажмите кнопку **«Очистить папку»**;
2. Откроется страница **«Результат очистки»**, где отобразится отчет о проделанной работе.

Будут удалены файлы из папки `report`.

## 💾 Файлы приложения

После запуска рядом с приложением могут появиться следующие папки:

| Папка | Назначение                                       |
| ---------- | ---------------------------------------------------------- |
| `logs`   | Файлы журналирования программы |
| `report` | Сохранённые текстовые отчёты     |

## 🌌 Дополнительная информация

- Встроенный словарь содержит русские существительные.
- Поиск выполняется без учёта регистра.
- Длина слова должна быть не меньше двух символов.
- Пробелы во введённых параметрах автоматически удаляются.
- Приложение использует локальный веб-сервер и не требует подключения к интернету после запуска.

## 🐞 Частые проблемы

### Веб-страница не открылась автоматически

Скопируйте и откройте в браузере любой из адресов:

- `http://localhost:8000`.
- `http://localhost:8000/directory-analytics/new` .

### Порт уже используется

Если адрес `localhost:8000` недоступен, закройте другой экземпляр приложения или программу, которая использует порт `8000`.
